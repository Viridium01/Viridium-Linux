# Viridium Linux

*If it's not broken, don't fix it.*

An extremely fast, speed-oriented minimal Linux system that anyone can use. It comes with a pacman-like package manager (**vbuild**), a custom install script (**vinstall**), and full Arch repo and AUR support.

## Documentation

Everything you need is on the website: **https://viridiumlinux.github.io/**

- [Download and install](https://viridiumlinux.github.io/download/)
- [vbuild package manager guide](https://viridiumlinux.github.io/vbuild/)
- [FAQ and troubleshooting](https://viridiumlinux.github.io/faq/)

## Quick start

1. Grab the ISO from the [latest release](https://github.com/Viridium01/Viridium-Linux/releases/latest).
2. Boot it, log in as `root`, and run `vinstall`.
3. Update anytime with `vbuild -Syu`.
